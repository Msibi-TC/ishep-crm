- Configure the environment safely
- Set up public routes and landing pages
- Add modular structure for future workflows
- Confirm frontend build and test health

## Phase 2: membership CRM

- Create member and organization models
- Add member onboarding and verification workflows
- Implement access control and audit trails

## Phase 3: public portals

- Launch membership portal pages
- Add careers and bursaries public content
- Connect to CRM data models and review flows

## Phase 4: operational readiness

- Add reporting and audits
- Harden deployment configuration
- Prepare production and staging-based environment rules
